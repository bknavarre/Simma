# Simma - Good Food Comes Together

**Simma** ("Your kitchen in one place") is a smart meal planning, pantry staple, and grocery management React application built around the Simma design system.

## Brand Palette & Design Tokens
- **Sage (`#55624F`)**: Primary brand header & accent buttons.
- **Olive (`#7F8F6B`)**: Sub-headers & status badges.
- **Terracotta (`#C76F42`)**: Highlights, warnings & callouts.
- **Sand (`#F5EDE3`)**: Warm neutral backgrounds & card borders.
- **Charcoal (`#2E2E2E`)**: High contrast typography.
- **Cream (`#FCFAF7`)**: Canvas background.

## Brand Navigation & Core Pillars
1. **Save** (Pantry & Staples)
2. **Shop** (Smart Multi-Store Grocery List: H-E-B & Kroger)
3. **Plan** (Weekly Meal Calendar)
4. **Cook** (Recipe Vault & AI Importer)
5. **Enjoy** (Favorites & Family Notes)

## Local Setup & Deployment
```bash
npm install
npm run dev
```

To build for production / GitHub Pages:
```bash
npm run build
```
